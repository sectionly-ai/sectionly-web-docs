## Introduction

Welcome to Sectionly:AI Product Options! This AI-powered solution is designed to elevate the customization experience for Shopify stores, helping you effortlessly create unlimited product customization scenarios. Whether you want to offer personalized apparel, custom jewelry, or add exclusive configurations to electronics, Sectionly helps you break through conventional limitations and efficiently deliver unique shopping experiences that make your store stand out from the crowd.

## Core Features

<Columns cols={2}>
  <Card icon="zap" title="AI-Powered Quick Creation">
    Leverage AI to automatically generate product options and variants. Simply describe your needs in natural language (e.g., "add pattern, material, and personalized engraving options for phone cases") to quickly generate complex configurations. Supports images and attachments for enhanced clarity without manual tedious setup.
  </Card>

  <Card icon="history" title="Conversation History Management">
    Track and reuse previous configurations by viewing conversation history, continuing optimizations, or directly reusing setups to reduce configuration costs.
  </Card>

  <Card icon="palette" title="Comprehensive Option Type Coverage">
    Supports text fields, dropdowns, checkboxes, radio buttons, color swatches, image uploads, date pickers, and more input types. Perfect for all categories including apparel, jewelry, electronics, and other personalization scenarios—from basic specifications to deep customization like engraving and pattern design.
  </Card>

  <Card icon="brain" title="Smart Conditional Logic">
    Dynamically show or hide subsequent options based on user's previous selections, creating smooth and contextually relevant interactions (e.g., showing engraving text input only after selecting "engraving service"), enhancing shopping flow continuity and usability.
  </Card>

  <Card icon="shopping-cart" title="Flexible Add-on Product Configuration">
    Add supplementary products or services (like custom gift boxes, extended warranties) with separate pricing and inventory tracking rules. Eliminate the need to create multiple SKUs for pricing logic—handle multi-scenario pricing within a single product.
  </Card>

  <Card icon="download" title="Efficient Import/Export Management">
    Import or export option sets via JSON files for batch migration, cross-store replication, and backup recovery, easily handling large-scale management needs.
  </Card>

  <Card icon="monitor" title="Dual Display Mode Support">
    Supports both App Block (recommended) and App Embed display modes, compatible with different Shopify themes to ensure optimal frontend presentation.
  </Card>

## Workflow

<Steps>

<Step title={"Install the App"}>

Install the Sectionly:AI Product Options App from the Shopify App Store.
</Step>

<Step title={"Create Option Sets"}>

<Tabs>

<Tab title="AI Generation">
Go to the "AI Chat Page" and describe your needs in natural language (e.g., "create Valentine's Day necklace customization with material, pendant shape, and engraving options"). Preview, edit, and save the AI-generated configuration.
</Tab>

<Tab title="Template Reuse">
Select industry templates from the "Template Center" (like T-shirts), apply with one click, and adjust details (such as modifying color options and pricing rules).
</Tab>

<Tab title="Manual Creation">
Click "Create Option Set" in the "Option Sets List", add elements (input/selection/static elements), organize with grouping, and set product application scope (specific products or all products).
</Tab>

</Tabs>
</Step>

<Step title={"Optional Configuration (Not Required)"}>

<Tabs>

<Tab title="Conditional Display">
Set display conditions for elements, such as showing related options only when a specific option is selected.
</Tab>

<Tab title="Pricing Features">
Create dedicated pricing products to set price adjustments for specific options, enabling dynamic price calculations.
</Tab>

</Tabs>
</Step>

<Step title={"Set Display Mode (Choose One)"}>

<Tabs>

<Tab title="App Block (Recommended)">
Manually add to product pages with customizable positioning, faster loading, and SEO-friendly.
</Tab>

<Tab title="App Embed">
Automatically displays on all product pages without individual configuration, perfect for quick deployment.
</Tab>

</Tabs>
</Step>

<Step title={"Management and Application"}>

<Info>
**Status Management**

Option set status includes "Active" (effective, displays on frontend) and "Inactive" (disabled).
</Info>

<Warning>
**Priority Rules**

Exact matches (specific products) take priority over global applications. When multiple sets match the same product, the most recently updated option set takes precedence.
</Warning>
</Step>

</Steps>
